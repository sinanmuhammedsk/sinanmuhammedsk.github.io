Project Overview

The **College Bus Tracking & Management System** is a client-centric relational database application showcasing administrative student logistics. The implementation features an advanced in-memory SQL execution sandbox that runs standard query operations alongside virtual PL/SQL constraints completely inside the client-side browser runtime.

Key Modules & Architecture

1. SQL Database Sandbox Engine

An in-memory relational dataset parser built in JavaScript supporting SQL syntax queries including `SELECT`, `INSERT`, and `DELETE` transactions.

2. Virtual PL/SQL Triggers Simulator

Simulates procedural constraints and automated trigger validations. Handles student fee pass allocations, distance audits, and seating validations recursively.

3. Interactive Seat Allocator Grids

Visualizes passenger occupancy and seat logs dynamically in a micro-grid layout, highlighting booked, selected, and vacant student states.

4. Financial Ledger Audits

Administrative log panel executing transaction logs and trigger outputs to record database updates transparently for inspection.

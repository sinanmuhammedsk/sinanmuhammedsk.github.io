Project Overview

The **Student Performance Analysis and Prediction System** (SPAS) evaluates student tracking datasets using supervised learning analytics. By modeling academic factors, demographic attributes, and engagement metrics, SPAS identifies key predictors of student performance and outputs validated projections. The system presents regression metrics alongside dynamic forecast panels.

Key Modules & Architecture

1. Exploratory Data Analyser (EDA)

Parses demographics, attendance coefficients, and midterm scores. Computes correlation coefficients and plots distribution curves using stats libraries.

2. Regression Predictor Pipeline

Trains supervised regressions (including Linear Regression and Random Forest models). Executes automated hyperparameter search tuning to prevent overfitting.

3. Objective Model Evaluation

Calculates MSE (Mean Squared Error) and R2 Score tracking model convergence. Compares metrics across multiple algorithms to validate baseline fits.

4. Interactive Simulation Panel

Web dashboard console allowing instructors to adjust indicators (e.g. study time, attendance) to dynamically forecast expected GPA indicators.

Project Overview

The **Inventory & Demand Forecasting Platform** is a client-centric predictive dashboard tool migrating Python forecasting libraries into client-side web calculations. The platform aggregates pre-rendered historical warehouse datasets and enables low-latency modeling equations. It provides inventory managers with real-time insight into potential stocks, forecasted quantities, and anomalies in purchase operations.

Key Modules & Architecture

1. Client-Side Data Engine

Parses pre-aggregated dataset structures without requiring heavy database queries. Evaluates inventory fields, safety lines, and order cycles client-side in less than 20ms.

2. Forecasting Modeler

Features time-series mathematical prediction formulas. Allows managers to dynamically toggle alpha values for **Exponential Smoothing** and window sizes for **Moving Averages** to observe supply trends.

3. Analytics Charts Console

Leverages Chart.js to plot multi-line visual graphs. Displays stock trends, safety limits, order occurrences, and expected demand curves side by side with customizable filters.

4. Threat & Anomaly Logger

Tracks safety stock levels and triggers real-time visual alerts indicating high risks of stockouts or overstock warnings using client-side algorithms.

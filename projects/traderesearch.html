Project Overview

**TradeResearchAI** is a data-driven market intelligence platform that applies Natural Language Processing (NLP) to financial print feeds. By parsing earnings transcripts, financial news feeds, and official filings, the application computes micro-sentiment metrics and models visual indicators. These metrics are matched alongside asset price variations to suggest automated predictive trading trends.

Key Modules & Architecture

1. News Harvester & Aggregator

An automated crawler gathering financial press articles, social channels, and public earnings call transcripts. Normalizes varying markup layouts into raw text structures.

2. Semantic NLP Sentiment Parser

Leverages Lexicon-based and transformer models to identify positive, neutral, or negative sentiment weights. Measures semantic strength to assess public reactions.

3. Price Correlation Engine

Maps calculated sentiment metrics against stock price timeline ticks. Integrates timeseries regression models to evaluate lagging/leading signal changes.

4. Analytics Workspace UI

Styled dashboard mapping active ticker charts, text cloud analysis, transaction matrices, and signal recommendations in a clean obsidian design.
